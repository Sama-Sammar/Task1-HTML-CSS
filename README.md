# First HTML & CSS Task

## Description
This is my first task during the internship to practice HTML and CSS.  
The project is a simple responsive webpage with a header, navigation menu, cards section, and footer.

## Features
- **Header** with logo and navigation menu
  - Desktop navigation links
  - Mobile/Tablet hamburger menu
- **Responsive cards section** using CSS Grid
  - Adjusts layout based on screen size
  - Three cards on desktop, two on tablet, one on mobile
- **Footer** at the bottom
- **Responsive design** with media queries
- Basic styling with colors, shadows, spacing, and fonts
